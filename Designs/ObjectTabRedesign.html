Use in code

Read values through Grimoire Object Link

Choose a field and copy a complete example for a MonoBehaviour on the linked GameObject. The Object Link reads from the source selected in Grimoire settings.

Code example C# · inside a MonoBehaviour method
var link = GetComponent<
    Grimoire.PluginV2.GrimoireObjectLink>();
if (link != null &&
    link.TryGetNumber("hp", out var hp))
{
    // Use hp
}
One click copies the full example, not the current value.
For references, lists, and other field types, the example changes to the matching Object Link method.
